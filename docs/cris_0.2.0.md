# CRIS 0.2.0

## 1. Visão geral

A CRIS 0.2.0 inicia uma nova fase de desenvolvimento do projeto CRIS.

A versão 0.1 foi utilizada como base de aprendizado, experimentação e validação da estrutura inicial do projeto.

Ao final da CRIS 0.1, a estrutura principal estava funcionando e os testes definidos para a versão foram concluídos com **23/23 testes aprovados (100%)**.

A partir desse ponto, a CRIS 0.2.0 passa a utilizar essa base estável para desenvolver uma aplicação mais estruturada e preparada para evoluções futuras.

---

## 2. Ponto de partida

A CRIS 0.2.0 começa a partir de uma versão 0.1 considerada estável.

Estado de referência:

- CRIS 0.1 concluída;
- 23/23 testes aprovados;
- estrutura principal funcionando;
- Git e GitHub configurados;
- banco SQLite funcionando;
- núcleo da aplicação funcionando;
- geração de código Python funcionando;
- documentação inicial criada;
- versão 0.2.0 marcada no Git com a tag `v0.2.0`.

A tag `v0.2.0` representa oficialmente o início desta nova fase.

---

## 3. Objetivo da CRIS 0.2.0

O objetivo da CRIS 0.2.0 é transformar a base criada na versão 0.1 em uma estrutura mais útil, organizada e preparada para aplicações práticas.

Nesta fase, o desenvolvimento passa a priorizar:

- organização do projeto;
- funcionalidades práticas;
- reutilização de componentes;
- armazenamento de informações;
- automação;
- testes;
- documentação;
- preparação para execução em ambientes externos;
- evolução futura da CRIS.

---

## 4. Linguagem principal

A linguagem principal utilizada nesta fase continua sendo:

**Python**

O Python permanece como o centro do desenvolvimento da CRIS.

Bash e Shell Script poderão ser utilizados posteriormente para automação e administração do ambiente, mas não são o foco principal do desenvolvimento neste momento.

---

## 5. Princípios da CRIS 0.2.0

### 5.1 Simplicidade

A estrutura deve permanecer compreensível e evitar complexidade desnecessária.

### 5.2 Funcionamento antes de expansão

Uma funcionalidade deve funcionar corretamente antes de receber novas camadas ou recursos.

### 5.3 Testes

As funcionalidades importantes devem possuir testes para evitar regressões.

### 5.4 Documentação

As alterações relevantes devem ser registradas e documentadas.

### 5.5 Versionamento

O Git será utilizado para registrar a evolução do projeto.

Versões importantes serão identificadas por tags.

### 5.6 Evolução incremental

A CRIS será desenvolvida em etapas pequenas e verificáveis.

---

## 6. Estado inicial da versão 0.2.0

A versão 0.2.0 começa com a estrutura funcional herdada da CRIS 0.1.

O projeto possui:

- `main.py`;
- núcleo da CRIS;
- ferramentas;
- projetos;
- documentação;
- banco SQLite;
- testes;
- configuração Git;
- repositório GitHub.

A estrutura será modificada conforme novas necessidades forem identificadas.

---

## 7. Banco de dados

A CRIS possui uma base SQLite utilizada para armazenamento local.

Na versão anterior foram utilizadas estruturas para armazenar:

- conhecimento;
- variáveis;
- informações relacionadas ao funcionamento da CRIS.

A CRIS 0.2.0 poderá ampliar essa estrutura conforme novas funcionalidades forem desenvolvidas.

---

## 8. Testes

Os testes continuam sendo parte fundamental do desenvolvimento.

A CRIS 0.1 terminou com:

**23/23 testes aprovados — 100%**

Esse resultado será utilizado como referência para a evolução da versão 0.2.0.

Novas funcionalidades deverão ser testadas antes de serem consideradas concluídas.

---

## 9. Git e GitHub

O projeto utiliza Git para controle de versão e GitHub para armazenamento do código.

A versão inicial da nova fase foi registrada através da tag:

`v0.2.0`

Essa tag representa o ponto inicial oficial da CRIS 0.2.0.

O histórico do Git deverá permanecer como registro da evolução do projeto.

---

## 10. Desenvolvimento da versão 0.2.0

A CRIS 0.2.0 será desenvolvida de maneira incremental.

Cada nova funcionalidade deverá seguir, sempre que possível, o ciclo:

1. definir o objetivo;
2. implementar;
3. testar;
4. corrigir;
5. documentar;
6. registrar no Git;
7. continuar para a próxima etapa.

---

## 11. Critério de conclusão

Uma funcionalidade da CRIS 0.2.0 será considerada concluída quando:

- estiver implementada;
- estiver funcionando;
- tiver sido testada;
- não apresentar erros conhecidos que impeçam seu uso;
- estiver documentada quando necessário;
- estiver registrada no histórico do projeto.

---

## 12. Próximos passos

A partir da tag `v0.2.0`, o desenvolvimento continuará sobre a base estável da CRIS 0.1.

Os próximos recursos serão definidos conforme as necessidades do projeto.

A prioridade será construir uma CRIS funcional, modular, testável e preparada para futuras expansões.
